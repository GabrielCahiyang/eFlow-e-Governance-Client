# eFlow empty-state illustrations

Artwork by Katerina Limpitsouni / unDraw, selected from https://undraw.co/search/empty on 18 October 2026.
License: https://undraw.co/license (reviewed on the same date). Use is permitted in personal and commercial projects without attribution. These files are bundled as eFlow UI decoration, not an illustration library or asset distribution product. The license prohibits competing asset services, asset packs and AI/ML training use.

The site's color picker was set to eFlow's light theme primary color, `#0c6f6b`. The displayed SVG vectors use `currentColor`; each saved SVG sets this accent on its root. Paths, proportions and other colors are preserved. Files are served locally; no runtime calls to unDraw are required.
