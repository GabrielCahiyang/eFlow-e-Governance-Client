# Role × action freeze

The screen register covers discovery; this matrix covers action eligibility. Role is necessary context, never sufficient record authority. “Server source” means the cited local service/migration was inspected; no deployed authorization audit occurred in 8A. Every handler candidate also has a row in [mutations.json](inventory/mutations.json), including unresolved individual details.
